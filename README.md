# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# 🔐 Random Password Generator

A simple and responsive **Random Password Generator** built using React.js, Vite, and Tailwind CSS. This application allows users to generate random passwords with customizable options.

## ✨ Features

- Generate random passwords instantly.
- Adjustable password length (8–30 characters).
- Option to include numbers.
- Option to include special characters.
- One-click copy to clipboard.
- Automatic password generation when settings change.
- Clean and responsive user interface.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Vite

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🎯 Purpose

This project was created to practice React fundamentals, including useState, useCallback, useEffect, useRef, event handling, and dynamic UI updates.
